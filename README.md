# Operation Deadzone

A two-player co-op extraction shooter for Windows, made with Godot.

## Get the game

1. Download **[OperationDeadzone-windows.zip](../../releases/latest/download/OperationDeadzone-windows.zip)** (about 42 MB).
2. Right-click the zip and choose **Extract All**.
3. Double-click **UPDATE AND PLAY.bat**. If Windows shows a blue box, click **More info**, then **Run anyway**.

From then on, always start the game with **UPDATE AND PLAY.bat**. It fetches the newest
version when there is one, then starts the game. Your save is kept.

## Play with a friend

One of you clicks **HOST GAME** and sends the invite; the other clicks **JOIN FRIEND**,
pastes it and clicks **JOIN**. The details are in `HOW-TO-PLAY.txt` inside the game folder.
